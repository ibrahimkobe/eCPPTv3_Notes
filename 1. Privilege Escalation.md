## Extra Windows Post Exploitation
## 1. Persistence

Techniques used to maintain access to a compromised Windows host after the initial session ends.

| MSF Module / Command                        | Usage                                                                                                 |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `persistence_service`                       | Installs a persistence mechanism as a Windows service, so access survives reboots.                    |
| `enable_rdp`                                | Enables Remote Desktop Protocol on the target, providing an alternative access channel.               |
| `run getgui -e -u {UserName} -p {Password}` | Enables RDP and creates/configures a specified user account with the given credentials for RDP login. |

## 2. Hash Cracking

Offline cracking of captured Windows password hashes (typically NTLM).

| Tool / Command                   | Purpose                                                                                                         |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `john --format=NT {HashFile}`    | Cracks NTLM hashes using John the Ripper, specifying the NT hash format.                                        |
| `hashcat -a3 -m 1000 {HashFile}` | Cracks NTLM hashes using Hashcat — `-a3` selects brute-force attack mode, `-m 1000` selects the NTLM hash type. |

## 3. Credential Dumping

Extracting stored credentials, hashes, and secrets from a compromised host.

| Tool                       | Purpose                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Metasploit Meterpreter** | `hashdump` — dumps local user password hashes from the SAM database.                                                                                                                                                                                                                                                                                                                                      |
| **Kiwi**                   | Meterpreter's built-in credential harvesting extension (Mimikatz integration). Type `?` inside the Kiwi session to list all available commands.                                                                                                                                                                                                                                                           |
| **Mimikatz**               | Standalone credential harvesting tool. Key usage: <br> • Path: `/usr/share/windows-resources/mimikatz/x64/mimikatz.exe` <br> • `privilege::debug` — verifies debug privileges are active after spawning a shell (required for most operations) <br> • `lsadump::sam` — dumps credentials from the SAM database <br> • `sekurlsa::logonpasswords` — extracts logon passwords/credentials from LSASS memory |

## 4. Internal Enumeration

Post-exploitation reconnaissance modules used to map out the internal environment from a compromised host.

| MSF Module             | MSF Module       |
| ---------------------- | ---------------- |
| `enum_logged_on_users` | `enum_computers` |
| `enum_applications`    | `enum_patches`   |
| `checkvm`              | `enum_shares`    |
| `enum_av_excluded`     | `enable_rdp`     |
